## Overview

Graphia turns matrices into clear visual representations, making their structure, values, and patterns easier to understand at a glance than a grid of raw numbers.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/praneeth-cs/Graphia.git
cd Graphia
```
